# 스머프 에이전트 팀 메모리

> 팀의 공유 기억 저장소. 세션 간 맥락을 유지하고 축적된 지식을 보존한다.

## 사용법

- 똘똘이가 각 세션 종료 시 핵심 사항을 기록한다
- 새 세션 시작 시 이 문서를 먼저 읽고 맥락을 파악한다
- 오래된 항목은 삭제하지 않고 `완료` 표시 후 보관한다

## 프로젝트 컨텍스트

### 기술 스택
- App: Flutter (iOS/Android)
- Admin Web: Flutter Web
- Backend: NestJS (TypeScript)
- DB: PostgreSQL
- Cache: Redis
- Auth: JWT + Refresh Token
- Push: Firebase Cloud Messaging
- Storage: S3 호환 (MinIO / AWS S3)

### 주요 파일/경로
- 기획서: `1. Projects/병원-앱/기획서.md`
- 아키텍처: `1. Projects/병원-앱/아키텍처.md`
- 팀 규칙: `3. Resources/스머프-에이전트-팀/규칙.md`

### 알려진 제약사항
- 중소규모 병원 (의사 5~30명)
- 한국 개인정보보호법 + 의료법 준수 필수
- IT 비전문 원무과 직원이 관리 페이지 운영
