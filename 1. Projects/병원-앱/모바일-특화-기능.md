# 모바일 특화 기능 기획

## 개요

모바일 디바이스의 고유 능력(카메라, 센서, AI, 항시 휴대)을 활용하여 웹에서는 불가능한 차별화된 의료 경험을 제공한다.

---

## 1. AI 피부 진단 (셀카 기반)

### 기능 설명

- 셀카 촬영 → AI 피부 상태 분석 → 결과 카드 제공
- 피부 타입, 트러블 위치, 수분도, 색소침착 등 분석
- 시계열 비교: 이전 촬영과 변화 추적
- 진료 전 사전 정보로 의사에게 자동 전달

### 사용자 시나리오

김환자(30대 여성)가 피부 트러블이 생겨 피부과 예약을 잡았다. 예약 확인 화면에서 "진료 전 피부 분석하기" 버튼을 탭한다. 앱이 촬영 가이드를 보여주고(조명, 거리, 각도 안내), 셀카를 찍으면 AI가 15초 내로 분석을 완료한다. "T존 피지 과다", "볼 부위 붉음증 의심", "전반적 수분 부족" 등 결과 카드가 뜨고, 담당 의사에게 해당 이미지와 분석 결과가 진료 차트에 첨부된다. 진료실에 들어가기 전부터 의사가 상태를 파악하고 있어 진료 시간이 단축된다.

### 화면 흐름

```
촬영 가이드(조명·거리 안내)
  → 셀카 촬영
  → AI 분석 중 (로딩 애니메이션)
  → 결과 카드 (부위별 분석)
  → 이전 촬영과 비교 (타임라인)
  → 진료 연결 (차트 자동 첨부 확인)
```

### 주의사항

- "진단"이 아닌 "분석/참고 정보" 표현 사용 (의료법 준수)
- 면책 조항 표시 필수: "본 결과는 의료 진단이 아닌 참고 정보입니다"
- 피부과 전문 모듈과 연동
- 이미지 저장 시 개인정보 처리 방침 동의 필요

### Phase

> **Phase 2**

## 2. AI 챗봇 상담

### 기능 설명

- 24시간 병원 FAQ 챗봇 (진료시간, 주차, 준비사항 등)
- 증상 사전 체크: 증상 입력 → 추천 진료과 안내
- 예약 도우미: 대화형 예약 (챗봇이 안내하며 예약 완성)
- 복약 상담: 약 복용법, 부작용 문의
- 의료진 연결: 챗봇이 해결 못하면 1:1 메시지로 에스컬레이션

### 챗봇 유형 3가지

1. **FAQ 봇** (규칙 기반) — 자주 묻는 질문 즉답, MVP에 포함 가능
2. **증상 체크 봇** (AI) — 증상 입력 → 진료과 추천, Phase 2
3. **건강 상담 봇** (LLM) — 자유 대화형 건강 상담, Phase 3

### 사용자 시나리오

새벽 2시에 아이(5세)가 갑자기 열이 38.5도까지 오른다. 부모가 당황해 앱을 열고 챗봇에 "아이 열이 38도 넘어요"라고 입력한다. 챗봇은 즉시 추가 증상을 묻는다(기침 유무, 발진, 구토). 부모가 "기침은 없고 열만 나요"라고 답하면 챗봇이 "소아과 진료를 권장드립니다. 내일 오전 9시에 예약 가능합니다" 라며 빠른 예약 버튼을 제공한다. 동시에 "39도 이상이거나 경련이 있으면 즉시 응급실을 방문하세요 (119)" 안내가 고정 배너로 표시된다.

### 화면 흐름

```
채팅 UI (메시지 입력창)
  → 빠른 답변 버튼 (주요 FAQ 선택지)
  → AI 응답 (타이핑 애니메이션)
  → 진료과 추천 카드
  → 바로 예약 버튼
  → (필요 시) 의료진 1:1 메시지 연결
```

### 주의사항

- AI 응답 상단에 항상 명시: "본 답변은 의료 조언이 아닌 참고 정보입니다"
- 응급 키워드(흉통, 호흡곤란, 의식 저하 등) 감지 시 119 연결 안내 자동 표시
- LLM 환각(hallucination) 방지를 위한 병원 특화 RAG 구축 필요

### Phase

> **Phase 1** (FAQ 봇) → **Phase 2** (증상 체크) → **Phase 3** (LLM 상담)

## 3. 건강 정보 허브

### 기능 설명

- 개인 맞춤 건강 피드 (진료과, 연령, 질환 기반 추천)
- 질환별 정보 라이브러리 (증상, 원인, 예방, 치료)
- 의료진 직접 작성 콘텐츠 (우리 병원 의사가 알려주는 시리즈)
- 계절/시기별 건강 캠페인 (독감 시즌, 건강검진 권고 시기 등)
- 건강 퀴즈 (재미 + 교육 결합)
- 영상 콘텐츠 (운동법, 스트레칭 가이드 등)

### 콘텐츠 카테고리

| 카테고리 | 예시 콘텐츠 |
|---|---|
| 질환 정보 | 고혈압 완전 정복, 당뇨 식단 가이드 |
| 영양/식단 | 면역력 높이는 식품 TOP 5, 저염 레시피 |
| 운동/재활 | 무릎 통증 완화 스트레칭, 어깨 재활 운동 |
| 정신 건강 | 번아웃 자가 진단, 수면의 질 개선법 |
| 육아 | 예방접종 일정, 소아 발열 대처법 |
| 시즌 캠페인 | 독감 예방접종 안내, 봄철 알레르기 주의보 |

### 개인화 알고리즘

```
내 진료과 이력 (가중치 40%)
+ 연령대별 주요 질환 (가중치 30%)
+ 과거 조회 콘텐츠 기반 협업 필터링 (가중치 20%)
+ 계절/시기 요인 (가중치 10%)
= 개인 피드 순서 결정
```

### Phase

> **Phase 1** (기본 피드 + 정적 콘텐츠) → **Phase 2** (개인화 알고리즘) → **Phase 3** (영상 콘텐츠 + AI 추천)

## 4. 재미 요소 (Gamification)

### 기능 설명 — 건강을 게임처럼

- **건강 미션/챌린지**: 만보 걷기, 물 마시기, 약 제때 먹기 등 일일·주간 미션
- **출석 체크 포인트**: 앱 매일 접속 시 포인트 적립
- **건강 점수 & 레벨**: 미션 수행률 기반 내 건강 점수, 레벨업 시스템
- **복약 스트릭**: 연속 복약 기록 → 스트릭 달성 시 축하 애니메이션
- **건강 배지/업적**: "7일 연속 복약", "만보 5일 달성", "건강 퀴즈 만점" 등
- **포인트 리워드**: 적립 포인트 → 진료비 할인, 주차 할인 등 병원 내 혜택

### 게이미피케이션 시스템 설계

| 요소 | 메커니즘 | 보상 |
|---|---|---|
| 미션/챌린지 | 일일·주간 건강 행동 목표 설정 | 미션 완료 포인트 지급 |
| 스트릭 | 연속 달성일 카운트 | 7일·30일 달성 시 보너스 포인트 + 배지 |
| 레벨 | 누적 경험치 기반 (씨앗→새싹→나무→숲) | 레벨업 시 특별 배지 + 칭호 |
| 배지 | 특정 조건 달성 시 자동 부여 | 프로필 전시, 희귀 배지 수집 욕구 자극 |
| 포인트 | 모든 건강 행동에 포인트 적립 | 진료비 할인, 주차권, 병원 카페 할인 |

### 사용자 시나리오

당뇨 진단을 받은 이어르신(65세)이 매일 혈당을 기록해야 하지만 자꾸 잊는다. 앱을 설치하고 "혈당 기록 미션"을 수락하면, 매일 아침 9시에 알림이 온다. 기록하면 10포인트가 쌓이고, 7일 연속 달성 시 "꾸준함의 시작" 배지가 부여된다. 한 달 후 300포인트가 모이면 주차 1시간 무료권으로 교환할 수 있다. 어르신은 손자에게 "나 이제 레벨 3 나무야"라며 앱을 보여주며 뿌듯해한다.

### 주의사항

- 과도한 게이미피케이션 → 의료 앱 신뢰도 저하 위험, 절제가 핵심
- 건강 행동 촉진에 초점, 사용자 간 경쟁/순위는 최소화
- 포인트는 병원 자체 운영 시스템 (법적 화폐·금융 상품 아님, 법무 검토 필요)
- 고령 사용자 고려: UI 단순화, 큰 글씨, 직관적 아이콘

### Phase

> **Phase 2** (기본 미션 + 포인트 적립) → **Phase 3** (배지 + 레벨 + 리워드 교환소)

## 5. 모바일 센서 활용

### 기능 설명

- **만보기**: 스마트폰 가속도 센서로 걸음 수 자동 기록 (백그라운드 동작)
- **카메라 기반 심박수 측정**: 손가락을 후면 카메라+플래시에 대면 PPG 방식으로 심박수 측정
- **Apple Health / Google Fit 연동**: 기존 건강 데이터 가져오기 (걸음수, 수면, 체중 등)
- **수면 패턴 연동**: 수면 시간·질 데이터 시각화
- **진료 시 자동 데이터 첨부**: 최근 1개월 건강 데이터를 진료 차트에 첨부 (동의 후)

### 데이터 흐름

```
스마트폰 센서 / Health 앱
  → Flutter Health 패키지로 수집
  → 로컬 암호화 저장
  → 사용자 동의 후 병원 서버 전송
  → 의료진 차트에 표시
```

### Phase

> **Phase 2** (걸음수 + Apple Health·Google Fit 연동) → **Phase 3** (카메라 심박수 + 수면 데이터)

## 6. 기타 모바일 특화 기능

| 기능 | 설명 | Phase |
|---|---|---|
| **QR 체크인** | 병원 도착 시 QR 스캔으로 접수 완료, 대기표 자동 발급 | 1 |
| **위치 기반 도착 알림** | GPS로 병원 반경 200m 진입 감지 → 자동 접수 시작 알림 | 2 |
| **약 바코드 스캔** | 약 상자 바코드 촬영 → 복약 정보·주의사항 즉시 조회 | 2 |
| **음성 메모** | 진료 후 의사 설명 음성 메모 저장 (텍스트 자동 변환) | 3 |
| **홈 화면 위젯** | 다음 예약 일정, 오늘 복약 체크, 건강 점수 한눈에 확인 | 2 |

## 전체 Phase 로드맵 (모바일 특화)

```
Phase 1 (MVP)
├── FAQ 챗봇 (규칙 기반)
├── 기본 건강 정보 피드
└── QR 체크인

Phase 2
├── AI 피부 진단 (셀카)
├── 증상 체크 챗봇 (AI)
├── 게이미피케이션 (미션 + 포인트)
├── 모바일 센서 (만보기 + Health 앱 연동)
├── 위치 기반 도착 알림
├── 약 바코드 스캔
└── 홈 화면 위젯

Phase 3
├── LLM 건강 상담봇
├── 개인화 AI 피드 추천
├── 영상 콘텐츠
├── 고급 센서 (카메라 심박수 + 수면)
├── 배지 + 레벨 + 리워드 교환소
└── 음성 메모 (진료 내용 자동 변환)
```
