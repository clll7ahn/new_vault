# 전문모듈 상세 설계

## 설계 원칙
- 각 모듈은 독립 배포 가능, 공통모듈 인터페이스(SpecialtyModule) 준수
- DB 테이블은 모듈 접두사 사용 (im_, ortho_, derm_, ped_)
- 환자 앱 + 관리 페이지 화면 모두 포함

---

## 1. 내과 모듈 (internal-medicine)

### 핵심 기능
| 기능 | 설명 | 사용자 |
|------|------|--------|
| 만성질환 대시보드 | 당뇨/고혈압/고지혈증 통합 관리 | 환자 |
| 활력징후 트래킹 | 혈압/혈당/체중 입력+건강앱 연동 | 환자 |
| 복약 관리 | 약별 복용시간·용량 알림, 스트릭 | 환자 |
| 정기검진 리마인더 | 3/6개월 주기 재방문 자동 알림 | 시스템 |
| 수치 트렌드 차트 | 혈압/혈당 추이, 정상범위 표시 | 환자+의사 |
| 검사결과 해석카드 | 혈액검사를 쉬운 말로 요약 | 환자 |
| 환자 요약 뷰 | 수치·복약순응도·트렌드 한눈에 | 의사 |

### 화면 목록
앱: IM-A01~A07 (만성질환 대시보드, 수치입력, 트렌드차트, 복약관리, 검진리마인더, 검사해석, 설정)
관리: IM-W01~W03 (환자목록, 환자요약, 알림설정)

### DB 테이블
```sql
CREATE TABLE im_vitals (id, patient_id FK, type ENUM('bp','glucose','weight'), value_1 DECIMAL, value_2 DECIMAL, measured_at, note);
CREATE TABLE im_medications (id, patient_id FK, name, dosage, frequency, start_date, end_date, is_active);
CREATE TABLE im_med_logs (id, medication_id FK, taken_at, status ENUM('taken','skipped','late'));
```

### 의존 공통모듈: auth, medical-record, notification

## 2. 정형외과 모듈 (orthopedics)

### 핵심 기능
| 기능 | 설명 | 사용자 |
|------|------|--------|
| 통증 일지 | 부위/강도(1~10)/유형 기록, 시계열 | 환자 |
| 재활 운동 프로그램 | 부위별 운동영상/가이드, 일일체크 | 환자 |
| 수술 전후 체크리스트 | 준비사항, 회복 단계별 체크 | 환자 |
| 영상 비교 뷰어 | X-ray/MRI before/after 슬라이더 | 환자+의사 |
| 보조기 착용 일지 | 기브스/보조기 기간·상태 기록 | 환자 |
| 재활 진도 대시보드 | 운동수행률, 통증추이 한눈에 | 의사 |

### 화면 목록
앱: OR-A01~A06 (통증입력, 통증차트, 재활프로그램, 운동상세, 수술체크리스트, 영상비교)
관리: OR-W01~W03 (환자재활현황, 운동프로그램관리, 영상업로드)

### DB 테이블
```sql
CREATE TABLE ortho_pain_logs (id, patient_id FK, body_part, intensity INT, pain_type, note, logged_at);
CREATE TABLE ortho_rehab_programs (id, patient_id FK, doctor_id FK, title, exercises JSONB, start_date, end_date);
CREATE TABLE ortho_exercise_logs (id, program_id FK, exercise_name, completed BOOLEAN, logged_at);
```

### 의존 공통모듈: auth, medical-record, notification, content(운동영상)

## 3. 피부과 모듈 (dermatology)

### 핵심 기능
| 기능 | 설명 | 사용자 |
|------|------|--------|
| AI 피부 분석 | 셀카→AI 분석→점수+부위맵 | 환자 |
| 피부 사진 타임라인 | 부위별 촬영 시계열 비교 | 환자 |
| 시술 이력 관리 | 시술종류/날짜/비용/경과 기록 | 환자+의사 |
| Before/After 갤러리 | 치료 전후 비교 슬라이더 | 환자+의사 |
| 자외선 알림 | 날씨API 자외선지수 알림 | 환자 |
| 스킨케어 루틴 | 사용제품, 피부반응 기록 | 환자 |
| 시술 관리 뷰 | 환자별 시술이력, 경과사진 | 의사 |

### 화면 목록
앱: DM-A01~A07 (AI분석, 사진촬영, 타임라인, 시술이력, BA비교, 자외선, 스킨케어)
관리: DM-W01~W03 (환자피부이력, 시술등록, AI분석결과)

### DB 테이블
```sql
CREATE TABLE derm_skin_photos (id, patient_id FK, body_area, image_url, ai_result JSONB, score INT, taken_at);
CREATE TABLE derm_treatments (id, patient_id FK, doctor_id FK, type, description, cost, treated_at, next_date);
CREATE TABLE derm_skincare_logs (id, patient_id FK, products JSONB, skin_reaction, logged_at);
```

### 의존 공통모듈: auth, medical-record, notification, content

## 4. 소아과 모듈 (pediatrics)

### 핵심 기능
| 기능 | 설명 | 사용자 |
|------|------|--------|
| 성장 차트 | 키/몸무게 WHO곡선 백분위 표시 | 보호자 |
| 예방접종 스케줄 | 국가필수접종 일정, 완료체크 | 보호자 |
| 보호자 멀티자녀 | 아이 여러명 프로필 전환 관리 | 보호자 |
| 발달 체크리스트 | 월령별 발달이정표 체크 | 보호자 |
| 증상 일지 | 열/기침/발진 증상·시간 기록 | 보호자 |
| 수유/이유식 기록 | 수유간격, 이유식종류, 알레르기 | 보호자 |
| 성장 추적 대시보드 | 성장곡선, 접종현황 한눈에 | 의사 |

### 화면 목록
앱: PD-A01~A07 (자녀선택, 성장차트, 접종스케줄, 발달체크, 증상일지, 수유기록, 설정)
관리: PD-W01~W03 (환자성장추적, 접종관리, 발달평가)

### DB 테이블
```sql
CREATE TABLE ped_children (id, parent_id FK, name, birth_date, gender, blood_type);
CREATE TABLE ped_growth_logs (id, child_id FK, height DECIMAL, weight DECIMAL, head_circ DECIMAL, measured_at);
CREATE TABLE ped_vaccinations (id, child_id FK, vaccine_name, dose_number, scheduled_date, actual_date, status);
CREATE TABLE ped_symptom_logs (id, child_id FK, symptom_type, temperature DECIMAL, severity, note, logged_at);
```

### 의존 공통모듈: auth(보호자연동 필수), medical-record, notification
