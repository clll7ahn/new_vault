# 전문모듈 상세 설계 (Part 2)

## 5. 안과 모듈 (ophthalmology)

### 핵심 기능
| 기능 | 설명 | 사용자 |
|------|------|--------|
| 시력 추이 차트 | 좌/우안 시력 변화 라인차트 | 환자 |
| 렌즈/안경 처방 관리 | 도수, 교체주기 알림 | 환자 |
| 안압 기록 | 측정값 입력, 정상범위 알림 | 환자 |
| 시력 자가 테스트 | 간이 시력 측정 (참고용, 의료행위 아님) | 환자 |
| 안약 투약 알림 | 안약별 투약시간·횟수 알림 | 환자 |
| 눈 피로도 알림 | 화면사용시간 기반 20-20-20 룰 | 환자 |
| 시력 추적 대시보드 | 환자별 시력·안압 추이 | 의사 |

### 화면 목록
앱: OP-A01~A06, 관리: OP-W01~W02

### DB 테이블
```sql
CREATE TABLE oph_vision_logs (id, patient_id FK, eye ENUM('left','right'), vision DECIMAL, iop DECIMAL, measured_at);
CREATE TABLE oph_prescriptions (id, patient_id FK, type ENUM('glasses','lens'), sph_l, sph_r, cyl_l, cyl_r, prescribed_at, next_replace);
CREATE TABLE oph_eye_drops (id, patient_id FK, name, frequency, start_date, end_date);
```

### 의존 공통모듈: auth, medical-record, notification

## 7. 산부인과 모듈 (obstetrics)

### 핵심 기능
| 기능 | 설명 | 사용자 |
|------|------|--------|

| 산전 검진 스케줄 | 주수별 필수검사 자동 생성 | 산모 |
| 태아 검진 기록 | 초음파사진, 태아크기, 심박수 | 산모+의사 |
| 태동 카운터 | 태동 횟수·시간 기록, 일일패턴 | 산모 |
| 산모 건강 기록 | 체중, 혈압, 부종 등 상태 추적 | 산모 |
| 출산 준비 체크리스트 | 입원준비물, 신생아용품 | 산모 |
| 산모 관리 대시보드 | 주수별 상태, 검진 현황 | 의사 |

### 화면 목록
앱: OB-A01~A07, 관리: OB-W01~W03

### DB 테이블
```sql
CREATE TABLE ob_pregnancies (id, patient_id FK, due_date, lmp_date, status ENUM('active','delivered','loss'), created_at);
CREATE TABLE ob_checkups (id, pregnancy_id FK, week INT, type, results JSONB, ultrasound_url, checked_at);
CREATE TABLE ob_fetal_movements (id, pregnancy_id FK, count INT, duration_min INT, logged_at);
CREATE TABLE ob_maternal_logs (id, pregnancy_id FK, weight, blood_pressure, edema_level, note, logged_at);
```

### 의존 공통모듈: auth, medical-record, notification, appointment

## 8. 정신건강의학과 모듈 (psychiatry)

### 핵심 기능
| 기능 | 설명 | 사용자 |
|------|------|--------|
| 기분 트래커 | 일일 이모지+한줄메모, 주간패턴 | 환자 |
| 수면 일지 | 취침/기상, 수면품질, 패턴차트 | 환자 |
| 상담 일지 | 상담 내용 요약 (의사작성) | 의사→환자 |
| 약물 반응 기록 | 복약후 기분/부작용 기록 | 환자 |
| 마음챙김 가이드 | 호흡운동 타이머, 명상 가이드 | 환자 |
| 위기 핫라인 | 자살예방상담전화 즉시 연결 | 환자 |
| 기분 추이 대시보드 | 환자 기분·수면·약물반응 추이 | 의사 |

### 화면 목록
앱: PS-A01~A07, 관리: PS-W01~W03

### DB 테이블
```sql
CREATE TABLE psy_mood_logs (id, patient_id FK, mood_score INT, mood_emoji, note, logged_at);
CREATE TABLE psy_sleep_logs (id, patient_id FK, bed_time, wake_time, quality INT, note, logged_at);
CREATE TABLE psy_med_reactions (id, patient_id FK, medication, mood_before INT, mood_after INT, side_effects, logged_at);
CREATE TABLE psy_counseling_notes (id, patient_id FK, doctor_id FK, summary, patient_visible BOOLEAN, session_at);
```

### 의존 공통모듈: auth, medical-record, notification
### 특수 요구사항: 위기 핫라인 버튼은 앱 전역 플로팅 버튼으로 항상 접근 가능

## 모듈별 Phase 배정

| 모듈 | Phase 2 (핵심) | Phase 3 (고도화) |
|------|---------------|-----------------|
| 내과 | 활력징후+복약+트렌드 | AI 검사해석+건강앱연동 |
| 정형외과 | 통증일지+재활운동 | 영상비교뷰어+수술체크 |
| 피부과 | AI피부분석+사진타임라인 | 스킨케어+자외선알림 |
| 소아과 | 성장차트+접종스케줄 | 발달체크+수유기록 |
| 안과 | 시력추이+안약알림 | 자가테스트+렌즈관리 |
| 치과 | 치아차트+스케일링알림 | 교정기록+칫솔타이머 |
| 산부인과 | 주수트래커+검진스케줄 | 태동카운터+출산체크 |
| 정신건강 | 기분트래커+수면일지 | 마음챙김+약물반응 |

## 모듈 간 시너지

| 조합 | 시너지 효과 |
|------|------------|
| 내과+안과 | 당뇨 환자 안과 정기검진 자동 연계, 혈당↔안압 상관 추적 |
| 내과+정신건강 | 만성질환 우울증 스크리닝, 복약순응도↔기분 상관분석 |
| 소아과+안과 | 소아 시력 발달 추적, 성장기 근시 예방 알림 |
| 산부인과+내과 | 임신성 당뇨/고혈압 통합 모니터링 |
| 피부과+내과 | 약물 부작용 피부 반응 교차 추적 |
