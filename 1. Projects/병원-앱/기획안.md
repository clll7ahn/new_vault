# 병원 앱 기획안 (브레인스토밍 종합)

## 핵심 콘셉트

- "레고형 병원 앱" — 공통모듈(예약·대기·수납 등) + 진료과 전문모듈(내과·정형외과 등) 조합
- 병원이 자기 진료과에 맞는 모듈만 골라 맞춤 앱 구성
- 중소병원도 대형병원급 디지털 경험 제공

## 핵심 가치 3가지

1. 환자: "내 병원이 이렇게 편해졌다"
2. 병원: "전화·수작업 70% 감소"
3. 확장: "진료과 추가 = 모듈 추가"

## 타겟 사용자

- 환자: 20~60대, 중장년층 비중 높음
- 병원 직원: IT 비전문 원무과, 간호사
- 의료진: 진료 중 빠른 조회 필요
- 병원장: 경영 인사이트 필요

## 사용자 페인포인트 (브레인스토밍 종합)

### 환자 TOP 5

1. 대기 시간 불투명 — "지금 얼마나 기다려요?"
2. 예약했는데 또 1시간 대기
3. 접수 창구 줄 서기 (아픈 몸으로)
4. 처방전/서류 받으러 재방문
5. 내 진료 기록을 내가 모름

### 병원 직원 TOP 5

1. 같은 질문 전화 하루 수백 건
2. 노쇼 환자 관리 지옥
3. 수기 접수 → EMR 이중 입력
4. 진료실 호출 수동 관리
5. 월말 통계 엑셀 수작업

## 사용자 시나리오 3개

### 시나리오 1: 직장인 김환자의 점심 병원

점심시간 앱 예약 → 대기현황 보며 출발 → 사전문진 완료 → QR 체크인 → 40분 완료

> 앱 없이는 2시간 걸리던 과정이 40분으로 단축. "점심시간에 병원 갔다 올 수 있다"는 신뢰 형성.

### 시나리오 2: 원무과 박직원의 월요일 아침

앱 예약 30건 확인 → 노쇼 위험 자동 리마인드 → 취소 시 대기자 자동 배정 → 전화 0건

> 월요일 아침 전화 폭탄이 사라짐. 직원이 본업(환자 응대)에 집중할 수 있게 됨.

### 시나리오 3: 만성질환 이어르신의 재방문

어르신 모드로 큰 글씨 → 타임라인에서 처방 이력 확인 → 재예약 시 이전 정보 자동 첨부

> 자녀가 원격으로 예약 도와줄 수 있음. 어르신도 "내 병원 기록"을 직접 볼 수 있다는 자존감.

## UX 디자인 원칙 5개

1. **0클릭 도달** — 핵심 기능 홈에서 바로
2. **신뢰감 있는 차분함** — 네이비·슬레이트 팔레트
3. **글씨가 곧 UI** — 기본 18sp, 아이콘+텍스트 병행
4. **오류 없는 흐름** — Wizard UI, 뒤로가기 항상 허용
5. **상태가 보인다** — 어디서든 현재 상태 한눈에

## Phase 로드맵

### Phase 1 — MVP (3개월)

공통모듈 전체 + 킬러피처 5개 (대기열 투명 공개, 노쇼 방어, 사전 문진, 진료 타임라인, 어르신 모드)

### Phase 2 — 소통+전문모듈 (6개월)

보호자 연동 + 실시간 채팅 + 전문모듈 3개 (내과 / 피부과 / 정형외과)

### Phase 3 — 고도화 (1년)

AI 증상분류 + EMR 연동 + 전문모듈 확장 + 멀티병원 SaaS

## 성공 지표 (KPI)

- 앱 예약 전환율 30%+
- 노쇼율 50% 감소
- 전화 문의 70% 감소
- 환자 만족도 4.5/5+

## 안 하면 실패하는 것 3가지

1. **실시간 대기 시간 정확성** — 이 숫자가 틀리면 앱 신뢰 붕괴
2. **접수~진료 흐름 마찰 제로** — 앱 도입 후에도 종이 쓰면 이탈
3. **병원 직원이 쓰고 싶은 UI** — 직원이 팬이 되어야 환자 경험 완성
